## 🔧 Configuration

## 🚨 Troubleshooting

**Port already in use?**
```bash
# Change PORT in .env and restart
PORT=3001
npm start
```

**Can't login?**
- Check username/password in `.env`
- Make sure server is running
- Try another browser

**Data not showing?**
- Refresh the page
- Logout and login again
- Check browser console (F12)

**Server won't start?**
```bash
# Reinstall everything
rm -rf node_modules package-lock.json
npm install
npm start
```
